# Moonlight Krathong (Purple / Gold)

A static web app using Three-inspired CSS 3D layered raft visuals, GSAP animations and Supabase.

## GitHub
Upload `index.html`, `style.css`, `app.js` and this README to your repository root. Static hosting (GitHub Pages / Vercel) works.

## Supabase setup
1. Open SQL Editor and run `supabase.sql`.
2. In `app.js`, replace `PASTE_YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY_HERE` with your project's publishable/anon key. The project URL is already filled in.
3. Use the Publishable key only (never service-role/secret key).

This app stores public sender names and wishes, so don't enter sensitive personal details.
